## 🚀 Fitur Utama
1. **Sinkronisasi API:** Mengambil data dari API FastPrint dengan password dinamis (MD5 + Date) dan normalisasi data (Kategori & Status).
2. **Filtering:** Menampilkan produk hanya dengan status "bisa dijual".
3. **CRUD System:** Fitur Tambah, Edit, dan Hapus produk.
4. **Validasi:** Validasi backend untuk memastikan input nama dan harga (angka) sesuai.
5. **Keamanan:** Bypass SSL verification (development mode) dan proteksi Mass Assignment.
